# Plan: Font lebih ringan untuk LCP (pilihan a: subset Archivo)

**Tanggal:** 2026-10-21
**Status:** ✅ Langkah Archivo selesai. Langkah Geist menunggu keputusan user

## Masalah

LCP beranda di Lighthouse mobile ±3,1–3,4 s; target spesifikasi < 3 s. Archivo (±88 KB) memuat semua ketebalan dan lebar, padahal judul hanya memakai lebar 125% dan ketebalan 800–900.

## Hasil

| Bagian | Yang dibuat |
|--------|-------------|
| Skrip | `npm run fonts` (`scripts/subset-fonts.mjs`, devDependency `subset-font` 2.9.0, **BSD-3-Clause**, bukan MIT seperti tertulis di draft): unduh Archivo dari google/fonts (dikunci ke commit `95f4904`, 2026-03-03), kunci lebar 125, ketebalan 800–900, huruf Latin termasuk Latin Extended-A, tanda baca, € ™ −, panah, ⌘. Metadata lisensi (name ID 13, 14) dipertahankan di dalam font |
| Font | `app/fonts/archivo-display.woff2`: **88 KB → 28 KB**, plus `app/fonts/Archivo-OFL.txt` (lisensi SIL OFL; Archivo tidak punya Reserved Font Name) |
| Memuat | `next/font/local` di `app/layout.tsx` (`weight: "800 900"`, `font-stretch: 125%`) |
| Tampilan | Judul sama persis (screenshot beranda, artikel, authors, footer). **Satu perubahan kecil:** panah → dan ← kini digambar Archivo (lebih tebal, serasi dengan teks), sebelumnya memakai font cadangan. ↗ tidak ada di Archivo, jadi tetap seperti dulu |

### Pengukuran (Lighthouse mobile, median 3 run)

| Halaman | Simulasi: sebelum → sesudah | Throttling sungguhan (sesudah) | Elemen LCP |
|---------|------------------------------|-------------------------------|------------|
| Beranda | 3,31 → 3,10 s | **2,65–2,72 s** ✅ | Paragraf intro (Geist) |
| Artikel | 3,70 → 3,41 s | **2,55–2,59 s** ✅ | Foto sampul Picsum |
| Authors | 3,16 → **2,98 s** ✅ | **2,03–2,07 s** ✅ | Judul (Archivo) |

Di browser tanpa simulasi, LCP beranda teramati di 177 ms. Sisa selisih pada angka simulasi terutama berasal dari JavaScript framework (±190 KB) dan, di halaman artikel, foto Picsum yang dimuat lewat redirect, bukan dari font.

### Perbedaan dari plan

| Plan | Yang terjadi | Alasan |
|------|--------------|--------|
| Langkah 4: kalau masih ≥ 3 s, potong Geist | **Belum dikerjakan, menunggu keputusan user** | Dengan throttling sungguhan semua halaman sudah < 3 s; Geist hanya 29 KB dan pengukuran menunjukkan font bukan lagi penyebab utama. Plan melarang langkah berikutnya diambil diam-diam |
| Lisensi `subset-font` "MIT" | BSD-3-Clause | Koreksi |
| Subset Latin dasar | Ditambah Latin Extended-A, € ™ −, rentang panah lengkap | Temuan review: nama atau judul dengan ş ă ł ő di Fase 2+ akan tampil dengan font cadangan. Ukuran naik 22 → 28 KB, LCP praktis sama |
